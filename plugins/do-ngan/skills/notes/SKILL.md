# โน้ตบนบอร์ดทีม

## อ่าน / ค้น — `list_notes`

`team` = ชื่อ/id ทีม · `search` = คำค้น · ได้ `note_id` สำหรับแก้

## แปะใหม่ — `create_note`

| ฟิลด์ | ความหมาย |
|---|---|
| `body` | เนื้อหา (บรรทัดแรกทำหน้าที่เป็นหัวข้อ) |
| `links` | รายการ URL |
| `team` | ทีมที่จะแปะ · ไม่ระบุ = ทีมเริ่มต้น |
| `color` | hex เช่น `#FDE68A` |
| `access` | ใครแก้/ลบได้: `everyone` ทุกคน · `members` เฉพาะคนใน `editors` (อ่านได้ทั้งบริษัทเสมอ) |
| `editors` | รายชื่อพนักงานที่แก้ได้ (ใช้คู่ `access: "members"`) |
| `visibility` | `private` = เห็นเฉพาะผู้สร้างกับเจ้าของบริษัท |

โน้ตใหม่ขึ้นบนสุดของบอร์ด ไม่แน่ใจว่าทีมไหน → `list_teams` แล้วถาม

## แก้ — `update_note`

`note_id` + ฟิลด์ที่เปลี่ยน (`body` `links` `color` `access` `editors` `visibility`) · `null` = ล้างค่า
`links` และ `editors` = **ชุดใหม่ทั้งหมด** — จะเพิ่มลิงก์ต้องอ่านของเดิมจาก `list_notes` แล้วส่งรวมกัน

## ใช้ร่วมกับเรื่องอื่น

- สรุปงาน (skill `standup`) แล้วผู้ใช้อยากแปะให้ทีมเห็น → `create_note`
- ไม่มี tool ลบโน้ต — ถ้าผู้ใช้อยากลบ ให้ลบบนหน้าเว็บ
