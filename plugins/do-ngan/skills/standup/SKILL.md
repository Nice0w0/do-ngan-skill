# สรุปงาน

## ขอบเขต

- ไม่ระบุ → ของผู้ใช้เอง ช่วง "เมื่อวานถึงวันนี้"
- "ทีม ..." → ทั้งทีมนั้น · "สัปดาห์นี้" → ตั้งแต่วันจันทร์ (เวลาไทย)
- ไม่แน่ใจว่าทีมไหน → `list_teams` แล้วถาม

## ดึงข้อมูล

1. `summarize_work` — `employee: "me"` หรือ `team: "<ชื่อทีม>"` และ `days` (รายวัน = 1, รายสัปดาห์ = 7)
   ตัวเลขในผลคิดจากข้อมูลจริงแล้ว ให้เรียบเรียงจากผลนี้ ห้ามนับใหม่เอง
2. อยากได้ว่าใครทำอะไรเมื่อไรแบบละเอียด → `get_activity` กรองตามพนักงานและช่วงวัน

## รูปแบบ (ภาษาไทย สั้น อ่านบนมือถือได้)

```
สรุปงาน <ใคร/ทีม> · <ช่วงวัน>

เสร็จแล้ว
• ...

กำลังทำ
• ... (xx%)

ติดอยู่ / เลยกำหนด
• ... — <เหตุผลถ้ามี>

ถัดไป
• ...
```

- ข้ามหัวข้อที่ว่าง · ไม่ใส่ id · ไม่แต่งเรื่องที่ไม่มีในข้อมูล
- ทีมใหญ่ → จัดกลุ่มตามคน คนละไม่เกิน 3 บรรทัด
- จบแล้วถามว่าจะให้แปะเป็นโน้ตบนบอร์ดทีมไหม (`create_note`) — ไม่ทำเองถ้าไม่ได้สั่ง
