# บอร์ดและการค้นงาน

## เลือก tool ให้ตรงคำถาม

| คำถาม | tool |
|---|---|
| ภาพบอร์ดทั้งบริษัท/ทีม ใครถืออะไร เรียงแบบบนเว็บ | `get_board` (`team` ถ้าระบุทีม · `include_done` ถ้าอยากเห็นงานเสร็จ) |
| ค้น/กรองงาน | `list_tasks` |
| รายละเอียดงานใบเดียว (ผู้ถือ ไฟล์แนบ ยอดแผ่นงานย่อย ประวัติ %) | `get_task` |
| พนักงานทั้งหมด ตำแหน่ง แบบงาน ทีม จำนวนงานค้าง | `list_employees` (`include_inactive` รวมกล่องที่ปิดแล้ว) |
| ทีมและสมาชิก | `list_teams` |

## ตัวกรองของ `list_tasks`

- `assignee` — ชื่อ/id หรือ `me` (รวมงานที่ถือร่วม) · `unassigned: true` = งานในกองที่ยังไม่มีผู้รับ
- `status` — รายการ เช่น `["open","doing"]` · ระบุ `done` แล้วจะรวมงานเสร็จให้เอง
- `priority` — รายการ เช่น `["hotfix","urgent"]` · `lane` — `routine` / `urgent`
- `project` — ชื่อ/id · `search` — คำในชื่อหรือรายละเอียด
- `overdue: true` — เลยกำหนดแล้วแต่ยังไม่เสร็จ · `due_within_days: N` — ครบกำหนดภายใน N วัน
- `include_done` — ค่าเริ่มต้นไม่รวมงานเสร็จ · `limit` — ค่าเริ่มต้น 50 สูงสุด 500

## คำถามที่พบบ่อย

- **ใครถืองานเยอะสุด** → `list_employees` (มีจำนวนงานค้างในมือ) เรียงจากมากไปน้อย หรือ `summarize_work` สำหรับภาระงานรายคนพร้อมงานเลยกำหนด
- **งานเลยกำหนด** → `list_tasks` `overdue: true` จัดกลุ่มตามผู้ถือ บอกว่าเลยมากี่วัน
- **ใครว่าง / ควรให้ใครทำ** → `list_employees` ดูงานค้างน้อยสุดในทีมที่เกี่ยวข้อง แล้วเสนอ ไม่มอบหมายเอง
- **งานค้างในกอง** → `list_tasks` `unassigned: true`

ผลเยอะ → สรุปเป็นตัวเลขก่อน แล้วแสดงรายการสำคัญ ไม่ต้องไล่ทุกใบ
