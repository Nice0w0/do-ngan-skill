# สร้างงาน

## จากประโยคเดียว

ผู้ใช้พิมพ์ เช่น "ให้ปอนด์แก้เซิร์ฟเวอร์ล่ม ก่อนเที่ยง ด่วนมาก"

1. `parse_task_text` `text` = ประโยคเดิม → ได้ชื่องาน รายละเอียด วันที่ เลน ความสำคัญ และผู้รับที่แนะนำ (ยังไม่สร้าง · ใช้โควตา AI ของบริษัท)
2. ทวนให้ผู้ใช้ดูบรรทัดเดียว เช่น `"แก้เซิร์ฟเวอร์ล่ม" → ปอนด์ · จิกปะทะ · ด่วนมาก · ครบ 2026-09-22`
   ถ้าผู้รับเป็นแค่ "คำแนะนำ" (ผู้ใช้ไม่ได้ระบุชื่อ) ต้องบอกว่าเป็นคำแนะนำ
3. ผู้ใช้ตกลง → `create_task`

ประโยคชัดเจนครบอยู่แล้ว สร้างตรงด้วย `create_task` ได้เลยไม่ต้อง parse

## หลายงานพร้อมกัน

รายการหลายบรรทัด → สร้างทีละใบด้วย `create_task` ทวนเป็นตารางสั้น ๆ ก่อนสร้างทั้งหมด

## ฟิลด์ของ `create_task`

| ฟิลด์ | ใช้เมื่อ |
|---|---|
| `text` | ชื่องานสั้น ๆ (จำเป็น) |
| `description` | รายละเอียด ลิงก์ เงื่อนไขส่งงาน |
| `assignees` | `["ปอนด์"]` · หลายคน = คนแรกผู้ถือหลัก ที่เหลือผู้ถือร่วม · ไม่ใส่ = ไปกองรอคนหยิบ |
| `lane` | `urgent` = งานจิกปะทะ · ค่าเริ่มต้น `routine` (พนักงานแบบคิวถูกบังคับเป็นรูทีน) |
| `priority` | `hotfix` ด่วนมาก · `urgent` ด่วน · `normal` · `low` ไม่รีบ · `someday` ทำเมื่อว่าง |
| `start_date` / `end_date` | `YYYY-MM-DD` · `end_date` = วันครบกำหนด |
| `project` | ผูกเข้าโปรเจค (ต่อท้ายพิมพ์เขียว) |
| `visibility` | `private` = เห็นเฉพาะผู้ถือกับเจ้าของบริษัท (ต้องมอบให้ตัวเอง) |
| `to_folder` | ไม่มีผู้รับ → เก็บเข้าโฟลเดอร์แทนลอยในกอง |
| `reminder` | ตั้งเตือนพร้อมกัน — ดูรูปแบบใน skill `reminder` |

## ระวัง

- "ด่วน" ในคำพูดอาจหมายถึงเลน (จิกปะทะ) หรือ priority ก็ได้ — งานแทรกกะทันหันใช้ `lane: urgent` ร่วมกับ priority
- ชื่อผู้รับซ้ำ → tool คืนตัวเลือก → ถามผู้ใช้
- หลังสร้าง บอกผลสั้น ๆ: ชื่องาน · ผู้ถือ · วันครบกำหนด
