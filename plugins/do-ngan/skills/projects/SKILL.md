# โปรเจค

## ดู

- `list_projects` — `status`: `active` (ค่าเริ่มต้น) / `done` / `all` → % ผู้ถือ งานเสร็จ/ทั้งหมด
- `get_project` — `project` = ชื่อ/id → งานทั้งหมดเรียงตามพิมพ์เขียว เช็คลิสต์ ประวัติ %
- "โปรเจคไปถึงไหน" → `get_project` แล้วสรุป: % · เสร็จกี่งานจากทั้งหมด · งานที่ค้าง/เลยกำหนด · วันจบโปรเจค

## สร้าง — `create_project`

`name` (จำเป็น) · `description` · `members` (ผู้ถือ) · `lane` (เลนที่โผล่บนบอร์ดผู้ถือ ค่าเริ่มต้น `routine`)
`color` hex เช่น `#5B7FB0` · `start_date` / `end_date`

## แก้ — `update_project`

ส่งเฉพาะที่เปลี่ยน · `null` = ล้างค่า
- `members` = **ผู้ถือชุดใหม่ทั้งหมด** — เพิ่มคนต้องใส่คนเดิมด้วย (ดูจาก `get_project` ก่อน)
- ปิดโปรเจค → `status: "done"` · เปิดใหม่ → `"active"`

## ความคืบหน้า — `set_project_progress`

- ตั้งเอง: `progress` 0–100 + `reason`
- คำนวณจากงานที่เสร็จ (แบบปุ่ม "คำนวณ %" บนเว็บ): `from_tasks: true`
- ไม่แน่ใจ → เสนอ `from_tasks` ก่อน เพราะอิงข้อมูลจริง

## งานในโปรเจค

- ย้ายงานเข้า: `add_task_to_project` `task_id` + `project` (ต่อท้ายพิมพ์เขียว)
- ถอดออก: `project: null`
- สร้างงานใหม่ในโปรเจคเลย: `create_task` ใส่ `project` (ดู skill `create-task`)
