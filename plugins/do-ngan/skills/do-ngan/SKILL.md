# ดูงาน (Do Ngan)

บอร์ดติดตามงานทีม เชื่อมผ่าน MCP server `do-ngan` (https://do-ngan.com/mcp) ทำงานในนามบัญชีของผู้ใช้
สิทธิ์เท่ากับบนหน้าเว็บทุกอย่าง — เห็นและแก้ได้เท่าที่ผู้ใช้ทำได้บนเว็บ

## ก่อนเริ่ม

- ถ้า tool ของ `do-ngan` ไม่มีให้เรียก หรือตอบว่ายังไม่ได้ยืนยันตัว ให้บอกผู้ใช้ล็อกอิน:
  - Claude Code: พิมพ์ `/mcp` → เลือก `do-ngan` → Authenticate
  - Codex: รัน `codex mcp login do-ngan` (หรือเปิด `/mcp` ใน Codex)
  แล้วล็อกอินด้วยบัญชีดูงาน กด "อนุญาต" ในหน้าขอสิทธิ์
- ไม่แน่ใจว่าเป็นใคร/อยู่บริษัทไหน → `whoami` ก่อน

## คำศัพท์

| คำที่ผู้ใช้พูด | ในระบบ |
|---|---|
| งานรูทีน | `lane=routine` |
| งานจิกปะทะ / งานด่วนแทรก | `lane=urgent` |
| กล่องพนักงาน | employee |
| พนักงานแบบคิว | employee `queue` — ใช้เลนเดียว |
| ยังไม่เริ่ม / กำลังทำ / รอรีวิว / เสร็จ | `open` / `doing` / `review` / `done` |

## กติกา

- ระบุคน โปรเจค ทีม ด้วยชื่อได้เลย (`me` = ตัวผู้ใช้เอง) ถ้าชื่อซ้ำ tool จะคืนตัวเลือกพร้อม id → **ถามผู้ใช้** ห้ามเดาเลือกเอง
- งานต้องอ้างด้วย id — หา id ด้วย `list_tasks` / `my_tasks` / `get_board` ก่อนเสมอ
- วันที่เป็นเวลาไทย (Asia/Bangkok) รูปแบบ `YYYY-MM-DD` · ตอบผู้ใช้เป็นภาษาไทย
- **ยืนยันกับผู้ใช้ก่อน** `delete_task` (ลบผ่านทางนี้กู้คืนไม่ได้) และ `switch_company` (เปลี่ยนบริษัทบนหน้าเว็บด้วย)
- แผ่นงานย่อย: `read_sheet` ก่อน `update_sheet` เสมอ · ถ้ามีคนเปิดแผ่นอยู่ `update_sheet` จะปฏิเสธ → บอกผู้ใช้ให้ปิดแท็บนั้นก่อน
- **ปิดงาน = `review` (รอรีวิว) เสมอ** เมื่อผู้ใช้บอกว่างานเสร็จหรือทำครบแล้ว ให้ตั้ง `set_task_status` เป็น `review`
  ใช้ `done` (เสร็จ) เฉพาะเมื่อผู้ใช้สั่งชัด ๆ ว่าให้เปลี่ยนเป็นเสร็จ/เสร็จสิ้น/ปิดงาน
- `set_task_progress` ทำได้เฉพาะคนที่ถืองานใบนั้น และควรใส่เหตุผลสั้น ๆ เสมอ (ขึ้นในประวัติ)

## สั่งงานจากประโยค

ผู้ใช้พิมพ์ประโยคยาว ๆ เช่น "ให้ปอนด์แก้เซิร์ฟเวอร์ล่ม ก่อนเที่ยง ด่วนมาก"
→ `parse_task_text` เพื่อแยกผู้รับ กำหนดส่ง เลน → ทวนให้ผู้ใช้ดูสั้น ๆ ถ้ามีจุดกำกวม → `create_task`

## ทางลัดที่มีในปลั๊กอินนี้

- `today` — งานของฉันวันนี้ อะไรเลยกำหนด อะไรควรทำก่อน
- `log-work` — อัปเดตงานบนบอร์ดจากสิ่งที่เพิ่งทำในโค้ด
- `standup` — สรุปงานทีม/ของฉันเป็นข้อความพร้อมส่ง
