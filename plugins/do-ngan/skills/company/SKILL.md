# บัญชีและบริษัท

## ดูตัวเอง

`whoami` → ชื่อ บริษัทที่ใช้อยู่ เป็นเจ้าของบริษัทไหม และกล่องพนักงานที่ผูกอยู่
ถ้าไม่ได้ผูกกับกล่องพนักงาน ผู้ใช้จะถืองานเอง (`me`) หรือปรับ % งานไม่ได้ — บอกให้เจ้าของบริษัทผูกกล่องให้บนเว็บ

## บริษัททั้งหมด

`list_companies` → ทุกบริษัทที่บัญชีนี้เป็นสมาชิก พร้อมบอกว่าตอนนี้ใช้บริษัทไหน

## สลับบริษัท

1. `list_companies` ดูชื่อให้ตรงก่อน
2. **ถามยืนยัน** — บอกผู้ใช้ว่าหน้าเว็บของเขาจะสลับไปบริษัทนั้นด้วยเมื่อโหลดใหม่
3. `switch_company` ด้วย `company` = ชื่อ, slug หรือ id
4. `whoami` ยืนยันผล

ทุก tool หลังจากนี้ทำงานกับบริษัทใหม่ ถ้าผู้ใช้แค่อยากดูข้อมูลบริษัทอื่นครั้งเดียว ให้เตือนว่าต้องสลับกลับเองด้วย
