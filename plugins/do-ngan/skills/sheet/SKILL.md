# แผ่นงานย่อย

หา `task_id` ก่อน · `get_task` บอกได้ว่างานมีแผ่นงานไหมและยอดเสร็จ/ทั้งหมด

## อ่าน — `read_sheet` (ทำก่อนแก้ทุกครั้ง)

- `tab` = ชื่อแท็บ (ไม่ระบุ = แท็บแรก)
- `from_row` / `max_rows` (ค่าเริ่มต้น 1 / 200 สูงสุด 1000) — แผ่นยาวให้อ่านเป็นช่วง
- เลขแถวตรงกับบนหน้าเว็บ **แถว 1 = หัวตาราง**
- สรุปให้ผู้ใช้: ยอดเสร็จ/ทั้งหมด และแถวที่ยังไม่เสร็จ

## แก้ — `update_sheet`

ส่งหลายอย่างในคำสั่งเดียวได้ ระบบทำตามลำดับ: `add_statuses` → `set` → `append` → `remove_statuses`

| ส่วน | ใช้ทำ |
|---|---|
| `set` | แก้ทีละช่อง `{ row, column, value }` · `column` = ตัวอักษร (A, B) หรือชื่อหัวคอลัมน์ · `value: null` = ล้าง |
| `set` + `status_cell` | `true` = ทำเป็นช่องสถานะ (`value` = ชื่อสถานะ ไม่ใส่ = ยังไม่เริ่ม) · `false` = ถอดสถานะออก |
| `append` | เพิ่มแถวต่อท้าย `{ values: { "หัวข้อ": "...", "B": "..." }, status: "กำลังทำ" }` |
| `add_statuses` | เพิ่มสถานะของแผ่น `{ label, color? }` — ไม่นับว่าเสร็จ |
| `remove_statuses` | ลบสถานะที่แผ่นเพิ่มเอง (ชื่อหรือ key) — สถานะของระบบลบไม่ได้ |

- ช่องสถานะรับเฉพาะสถานะที่มีในแผ่น: ยังไม่เริ่ม / กำลังทำ / รอรีวิว / เสร็จ หรือที่แผ่นเพิ่มเอง
- แถวที่ทำเสร็จใช้ "รอรีวิว" ตามกติกาเดียวกับงาน เว้นผู้ใช้สั่งให้เป็น "เสร็จ"
- แก้เฉพาะค่า ไม่แตะสไตล์หรือรูปแบบ

## ถ้าถูกปฏิเสธ

มีคนเปิดแผ่นนี้บนหน้าเว็บอยู่ → `update_sheet` จะไม่เขียน (กันการบันทึกทับกัน)
บอกผู้ใช้ให้ปิดแท็บแผ่นงานนั้นก่อน แล้วสั่งใหม่ — ห้ามวนลองซ้ำเอง
