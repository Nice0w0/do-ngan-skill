# แผ่นงานย่อย

หา `task_id` ก่อน · `list_tasks` `has_sheet: true` หางานที่มีแผ่นงาน (ผลมี `sheet: {done, total}`)

## อ่าน — `read_sheet` (ทำก่อนแก้ทุกครั้ง)

- `tab` = ชื่อแท็บ (ไม่ระบุ = แท็บแรก)
- `from_row` / `max_rows` (ค่าเริ่มต้น 1 / 200 สูงสุด 1000) — แผ่นยาวให้อ่านเป็นช่วง
- เลขแถวตรงกับบนหน้าเว็บ **แถว 1 = หัวตาราง**
- สรุปให้ผู้ใช้: ยอดเสร็จ/ทั้งหมด และแถวที่ยังไม่เสร็จ

## แก้ — `update_sheet`

ส่งหลายอย่างในคำสั่งเดียวได้ ระบบทำตามลำดับนี้ และเลขแถวของแต่ละขั้นอ้าง **สภาพหลังขั้นก่อนหน้า**:
`add_statuses` → `delete_rows` → `insert_rows` → `move_rows` → `order_rows` → `set` → `append` → `format` / `column_widths` / `row_heights` / `freeze` → `remove_statuses`

**ค่าในช่อง**

| ส่วน | ใช้ทำ |
|---|---|
| `set` | แก้ทีละช่อง `{ row, column, value }` · `column` = ตัวอักษร (A, B) หรือชื่อหัวคอลัมน์ · `value: null` = ล้าง |
| `set` + `status_cell` | `true` = ทำเป็นช่องสถานะ (`value` = ชื่อสถานะ ไม่ใส่ = ยังไม่เริ่ม) · `false` = ถอดสถานะ |
| `set` + `priority_cell` | `true` = ติดแท็กความสำคัญ (`value` = ด่วนมาก/ด่วน/ปกติ/ไม่รีบ/ทำเมื่อว่าง ไม่ใส่ = ปกติ) · `false` = ถอดแท็ก |
| `append` | เพิ่มแถวต่อท้าย `{ values: { "หัวข้อ": "...", "B": "..." }, status: "กำลังทำ" }` |
| `add_statuses` / `remove_statuses` | เพิ่ม/ลบสถานะของแผ่น — สถานะของระบบลบไม่ได้ |

**โครงแถว** (แถว 1 = หัวตาราง ย้าย/ลบไม่ได้)

| ส่วน | ใช้ทำ |
|---|---|
| `delete_rows: [5, 9]` | ลบแถว แถวข้างล่างเลื่อนขึ้น (เลขแถวก่อนลบทั้งหมด) |
| `insert_rows: [{ before: 4, count: 2 }]` | แทรกแถวว่างเหนือแถว 4 |
| `move_rows: [{ rows: [8, 9], before: 2 }]` | ย้ายชุดแถวไปไว้เหนือแถว before (แถวสุดท้าย+1 = ไปท้ายตาราง) |
| `order_rows: [7, 2, 5, 3, 4, 6]` | เรียงชุดแถวใหม่ในตำแหน่งเดิมของชุดนั้น — ใช้จัดเรียงทั้งตาราง |

dropdown สถานะ/ความสำคัญ ความสูงแถว และเซลล์รวมย้ายตามแถวไปเอง · เซลล์รวมข้ามแถวที่ถูกฉีก = error ไม่มีอะไรถูกเขียน

**หน้าตา** (แตะเฉพาะรูปแบบ ค่าและสถานะอยู่ครบ)

| ส่วน | ใช้ทำ |
|---|---|
| `format: [{ range, bold, italic, underline, strike, color, background, font_size, align, valign, wrap }]` | `range` = `A1:D1`, `B` (ทั้งคอลัมน์), `2` (ทั้งแถว), `A2:A` หรือชื่อหัวคอลัมน์ · สี hex เช่น `#FEF3C7` · `null` = ล้างสี |
| `column_widths: [{ column: "รายการ", width: 360 }]` | ความกว้างคอลัมน์ (px) |
| `row_heights: [{ row: 1, height: 40 }]` | ความสูงแถว (px) |
| `freeze: { rows: 1 }` | ตรึงหัวตารางตอนเลื่อน (0 = เลิกตรึง) |

**กติกา**
- ช่องสถานะรับเฉพาะสถานะที่มีในแผ่น · ช่องความสำคัญรับเฉพาะ 5 ระดับ · ช่องหนึ่งเป็นได้อย่างเดียว
- แถวที่ทำเสร็จใช้ "รอรีวิว" ตามกติกาเดียวกับงาน เว้นผู้ใช้สั่งให้เป็น "เสร็จ"
- ความสำคัญไม่นับเข้ายอดเสร็จ/ทั้งหมดบนการ์ด

## ถ้าถูกปฏิเสธ

มีคนเปิดแผ่นนี้บนหน้าเว็บอยู่ → `update_sheet` จะไม่เขียน (กันการบันทึกทับกัน)
บอกผู้ใช้ให้ปิดแท็บแผ่นงานนั้นก่อน แล้วสั่งใหม่ — ห้ามวนลองซ้ำเอง
