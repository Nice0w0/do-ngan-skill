# จัดแผ่นงานให้เป็นระเบียบ

งานนี้ **เขียนทับหลายแถว** — ต้องทำตามขั้นตอนและได้คำตกลงก่อนเขียนเสมอ

## 1. อ่านทั้งแผ่น

หา `task_id` → `read_sheet` จนครบทุกแถว (ใช้ `from_row` ถ้ายาว) เก็บค่าเดิมทุกช่องไว้ในบทสนทนา = ข้อมูลสำรองสำหรับย้อนกลับ

## 2. ออกแบบแผ่นใหม่

**คอลัมน์มาตรฐาน** (แถว 1 = หัวตาราง): `สถานะ | รายการ | หน้า | หมายเหตุ` (+ `ความสำคัญ` ถ้าแผ่นมีเรื่องด่วน/ไม่ด่วนปนกัน — ใช้แท็กความสำคัญ ไม่ใช่ข้อความเปล่า)
- คอลัมน์อื่นที่มีข้อมูลจริง (เช่น ผู้รับ ลิงก์) → เก็บไว้ต่อท้าย ห้ามทิ้ง
- ข้อมูลที่อยู่ผิดคอลัมน์ (เช่น ชื่อหน้าปนในรายการ) → ย้ายไปคอลัมน์ที่ถูก

**เกลาข้อความ**
- ช่องรายการ: ประโยคเดียว บอกอาการ ไม่เกิน ~80 ตัวอักษร รายละเอียดที่เหลือย้ายไปหมายเหตุ
- คงความหมายเดิม ไม่แต่งเพิ่ม · คงเลข commit / ลิงก์ / ชื่อเฉพาะไว้ครบ

**แยกแถว** — แถวที่มีหลายเรื่อง ("ปุ่มไม่ขึ้น และ วันที่ผิด") → แยกเป็นแถวละเรื่อง สถานะเดิมตามกัน

**เรียงลำดับ**
1. สถานะ: กำลังทำ → ยังไม่เริ่ม → รอรีวิว → สถานะที่แผ่นเพิ่มเอง → เสร็จ
2. ความสำคัญ: ด่วนมาก → ด่วน → ปกติ → ไม่รีบ → ทำเมื่อว่าง (จากแท็ก หรือคำในข้อความ เช่น hotfix, บล็อกงาน)
3. หน้า (กลุ่มเดียวกันอยู่ติดกัน)

## 3. แสดงแผนก่อนเขียน

- สรุป: จำนวนแถวก่อน/หลัง · แยกกี่แถว · คอลัมน์ที่ย้าย/เพิ่ม
- ตัวอย่าง 5–10 แถวแรกของแผ่นใหม่ และแถวที่ข้อความถูกเกลามากที่สุด (เดิม → ใหม่)
- บอกว่าจะเขียนทับทั้งแผ่น และมีข้อมูลเดิมเก็บไว้ในบทสนทนาเผื่อย้อนกลับ
รอผู้ใช้ตกลง

## 4. เขียน — `update_sheet` คำสั่งเดียว (ถ้าแผ่นไม่ใหญ่มาก)

ใช้คำสั่งโครงแถวแทนการเขียนทับทุกช่อง — ค่า สไตล์ dropdown และความสูงแถวย้ายตามแถวไปเอง ปลอดภัยกว่ามาก
1. `delete_rows` — แถวว่าง/แถวซ้ำที่ผู้ใช้ตกลงให้ลบ
2. `insert_rows` — ที่ว่างสำหรับแถวที่แยกออกมา (แทรกใต้แถวต้นทาง)
3. `order_rows` — ลำดับใหม่ทั้งตาราง (เลขแถวหลังขั้น 1–2)
4. `set` — ข้อความที่เกลาแล้ว ค่าในแถวที่แยกออกมา ย้ายค่าข้ามคอลัมน์ · แท็กความสำคัญด้วย `priority_cell` ถ้าแผ่นมีคอลัมน์ความสำคัญ
5. หน้าตา: `format` หัวตาราง (ตัวหนา สีพื้น) · `column_widths` ให้ช่องรายการกว้างพอ · `freeze: { rows: 1 }`

- สถานะที่ต้องใช้แต่แผ่นยังไม่มี → `add_statuses` ในคำสั่งเดียวกัน
- ขั้นไหนผิด (เช่น เซลล์รวมข้ามแถว) ทั้งคำสั่งไม่ถูกบันทึก — แจ้งผู้ใช้ แล้วปรับแผน
- แผ่นใหญ่มาก → แยกเป็น 2 คำสั่ง: โครงแถวก่อน แล้ว `read_sheet` ดูเลขแถวใหม่ ค่อย `set` / `format`

## 5. ตรวจหลังเขียน

`read_sheet` อีกรอบ เทียบกับแผน — จำนวนแถว ยอดเสร็จ/ทั้งหมด ต้องเท่าเดิม (ยกเว้นแถวที่แยกเพิ่ม)
ไม่ตรง → รายงานผู้ใช้พร้อมเสนอเขียนกลับจากข้อมูลเดิม ห้ามแก้ต่อเองเงียบ ๆ

ถูกปฏิเสธเพราะมีคนเปิดแผ่นอยู่ → หยุด บอกผู้ใช้ปิดแท็บนั้นก่อน (ถ้าเขียนไปแล้วบางชุด บอกด้วยว่าค้างถึงแถวไหน)
