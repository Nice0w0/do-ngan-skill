# ประวัติกิจกรรม — `get_activity`

| ตัวกรอง | ใช้เมื่อ |
|---|---|
| `task_id` | ประวัติของงานใบเดียว |
| `employee` | กิจกรรมที่เกี่ยวกับคนนั้น (ชื่อ/id หรือ `me`) |
| `since` / `until` | ช่วงวันที่ `YYYY-MM-DD` เวลาไทย (`until` รวมวันนั้น) |
| `limit` | ค่าเริ่มต้น 50 สูงสุด 500 |

- "เมื่อวาน" → `since` = `until` = วันที่เมื่อวาน · "สัปดาห์นี้" → ตั้งแต่วันจันทร์
- เล่าเป็นลำดับเวลา: เวลา · ใคร · ทำอะไร · กับงานไหน — รวมเหตุการณ์ซ้ำ ๆ ของงานเดียวกันเป็นบรรทัดเดียว
- ต้องการสรุปภาพรวมพร้อมตัวเลข (งานเสร็จ ค้าง เลยกำหนด) → ใช้ skill `standup` แทน
- ประวัติ % ของงานใบเดียวดูได้ละเอียดกว่าจาก `get_task`
