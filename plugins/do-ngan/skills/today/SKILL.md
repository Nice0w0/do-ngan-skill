# งานของฉันวันนี้

1. `my_tasks` — งานทั้งหมดที่ผู้ใช้ถือ (รวมถือร่วม) แยกตามสถานะ
2. `list_notifications` — มีงานใหม่ที่เพิ่งได้รับ หรืองานที่รอรีวิวจากผู้ใช้ไหม
3. จัดกลุ่มแล้วตอบสั้น ๆ เป็นภาษาไทย ตามลำดับนี้ (ข้ามกลุ่มที่ว่าง):
   - **เลยกำหนด** — วันส่งก่อนวันนี้ (เวลาไทย) และยังไม่ `done`
   - **ครบกำหนดวันนี้**
   - **รอคุณรีวิว** — งานสถานะ `review` ที่ผู้ใช้ต้องตรวจ
   - **กำลังทำ** — `doing` พร้อม % ถ้ามี
   - **ยังไม่เริ่ม** — เรียงตามวันส่งใกล้สุด งานด่วน (`urgent`) ขึ้นก่อน
4. ปิดท้ายด้วยข้อเสนอ 1 บรรทัดว่าควรเริ่มงานไหนก่อน และเพราะอะไร

แต่ละงานแสดง: ชื่องาน · วันส่ง · โปรเจค (ถ้ามี) ห้ามแสดง id ให้ผู้ใช้ดู เว้นแต่ถาม
อย่าเปลี่ยนสถานะงานเองในขั้นนี้ — แค่รายงาน
