# ซิงก์ไฟล์ ↔ แผ่นงานย่อย

ทิศทางเดียว: **ไฟล์ → แผ่นงาน** (ไม่แก้ไฟล์ในโค้ด เว้นแต่ผู้ใช้สั่ง)

## 1. ระบุต้นทางและปลายทาง

- ไฟล์: จากที่ผู้ใช้บอก หรือหาใน repo (`docs/**/*bug*`, `*todo*.md`, `known-issues`) — เจอหลายไฟล์ให้ถาม
- งาน: ชื่องานที่ผู้ใช้บอก → `list_tasks` `search` → `get_task` ยืนยันว่ามีแผ่นงาน — จำคู่ไฟล์↔งานไว้ในบทสนทนา รอบหน้าไม่ต้องถามซ้ำ

## 2. อ่านทั้งสองฝั่ง

**ไฟล์** — แยกเป็นรายการ รองรับ:
- checklist `- [ ] ...` / `- [x] ...` (`[x]` = แก้แล้ว)
- bullet/เลขข้อ ที่มีคำว่า แก้แล้ว / fixed / ✅ / ~~ขีดฆ่า~~ = แก้แล้ว
- ตาราง markdown ที่มีคอลัมน์สถานะ
เก็บต่อข้อ: ข้อความ · หน้า/ส่วนที่เกี่ยวข้อง (ถ้ามี) · แก้แล้วไหม · commit ที่อ้างในบรรทัด (ถ้ามี)

**แผ่นงาน** — `read_sheet` ทั้งแผ่น (แผ่นยาวอ่านเป็นช่วงด้วย `from_row`) จำหัวคอลัมน์ เลขแถว สถานะรายแถว

## 3. จับคู่

- ข้อเดียวกัน = ความหมายเดียวกัน แม้ถ้อยคำต่างกันเล็กน้อย (ไม่ต้องตรงตัวอักษร) — ดูหน้า/ส่วนประกอบด้วย
- ไม่แน่ใจว่าซ้ำไหม → ถือว่า **ซ้ำ** และใส่ไว้ในรายงานให้ผู้ใช้ตัดสิน ดีกว่าเพิ่มแถวซ้ำ
- ข้อในแผ่นที่ไม่มีในไฟล์ → ไม่ลบ ไม่แตะ แค่รายงาน

## 4. หา commit ของข้อที่แก้แล้ว

ข้อที่ไฟล์บอกว่าแก้แล้วแต่ไม่มี commit ในบรรทัด:
- `git log --oneline -30` เทียบข้อความ commit · หรือ `git log --oneline -S "<คำสำคัญ>"`
- เจอ → ใช้ short hash (7 ตัว) · ไม่เจอ → เว้นว่าง ห้ามเดา

## 5. แสดงแผนก่อนเขียน

```
เพิ่มใหม่ 4 แถว · ตั้งรอรีวิว 3 แถว (พร้อม commit) · ข้ามที่ซ้ำ 12 · ไม่แน่ใจ 1
```
แสดงรายการย่อของแต่ละกลุ่ม แล้วรอผู้ใช้ตกลง

## 6. เขียนด้วย `update_sheet` คำสั่งเดียว

- `append` — ข้อใหม่ ใส่ตามหัวคอลัมน์ที่มีอยู่ (เช่น รายการ / หน้า / หมายเหตุ) · `status`: แก้แล้ว = "รอรีวิว" · ยังไม่แก้ = "ยังไม่เริ่ม"
- `set` — ข้อที่มีอยู่แล้วแต่เพิ่งแก้: ช่องสถานะ → "รอรีวิว" · ช่องหมายเหตุ → ต่อท้าย `commit abc1234` (อย่าเขียนทับหมายเหตุเดิม)
- **ห้ามตั้ง "เสร็จ"** — เสร็จต้องผ่านคนตรวจ (skill `review-queue`) เว้นผู้ใช้สั่งเอง
- ไม่มีคอลัมน์หมายเหตุ → ถามก่อนว่าจะเพิ่มคอลัมน์ไหม หรือใส่ commit ในช่องรายการ

ถูกปฏิเสธเพราะมีคนเปิดแผ่นอยู่ → บอกผู้ใช้ปิดแท็บนั้น แล้วสั่งซ้ำ (แผนเดิมใช้ได้ ไม่ต้องอ่านใหม่ถ้าไม่มีใครแก้)

## 7. รายงาน

ตัวเลขที่ทำจริง + ยอดเสร็จ/ทั้งหมดของแผ่นหลังซิงก์ (จากผลของ `update_sheet` หรือ `read_sheet` อีกรอบ)
